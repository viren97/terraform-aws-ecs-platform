# msk-serverless

Amazon MSK Serverless cluster with IAM (SASL/IAM over TLS) authentication. Outputs topic and consumer-group ARN prefixes so each client gets an IAM policy scoped to its own topics.

Usable on its own; see [`stack/`](../../stack) for how the modules are composed.
