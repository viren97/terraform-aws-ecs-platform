# rds-postgres

RDS PostgreSQL 16 for one service: isolated subnets, Multi-AZ, TLS enforced, storage autoscaling, master password managed and rotated by RDS in Secrets Manager (never in state), Performance Insights, slow-query logging.

Usable on its own; see [`stack/`](../../stack) for how the modules are composed.
